# Daily Quiz

The Daily Quiz feature provides computer science practice questions and tracks challenge participation. It enables students to test technical fundamentals and maintain continuous daily streaks.

- **Frontend Path:** `frontend/src/features/daily-quiz/`
- **Backend Path:** `backend/features/daily_quiz/`
- **Route:** `/daily-quiz`
- **Backend Services:** FastAPI and Supabase

Nothing outside this folder may import from it.
