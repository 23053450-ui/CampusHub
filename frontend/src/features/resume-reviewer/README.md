# Resume Reviewer

The Resume Reviewer feature provides automated PDF resume evaluation and scoring against placement standards. It analyzes resume content to identify key strengths and constructive improvements.

- **Frontend Path:** `frontend/src/features/resume-reviewer/`
- **Backend Path:** `backend/features/resume_reviewer/`
- **Route:** `/resume-reviewer`
- **Backend Services:** FastAPI

Nothing outside this folder may import from it.
