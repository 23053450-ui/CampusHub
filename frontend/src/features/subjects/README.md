# Subjects

The Subjects feature provides a dedicated study workspace for enrolled courses. It integrates course materials, document viewing, and an AI study companion.

- **Frontend Path:** `frontend/src/features/subjects/`
- **Backend Path:** `backend/features/subjects_ai/`
- **Route:** `/subjects/:subjectId`
- **Backend Services:** Supabase and FastAPI

Nothing outside this folder may import from it.
