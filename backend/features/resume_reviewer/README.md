# Resume Reviewer

The Resume Reviewer backend handles PDF resume parsing and ATS scoring analysis. It generates feedback summaries and placement recommendations based on uploaded candidate resumes.

- **Frontend Path:** `frontend/src/features/resume-reviewer/`
- **Backend Path:** `backend/features/resume_reviewer/`
- **Route:** `/api/v1/resume-reviewer`
- **Backend Services:** FastAPI

Nothing outside this folder may import from it.
